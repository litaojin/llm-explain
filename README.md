# LLM Explain · 用动图理解 AI

**在线学习：https://litaojin.github.io/llm-explain/**

四部分、30 课，每个动图讲清一个概念。全部动画合计 10 分 35 秒。

1. **模型怎样完成一次预测？**（10 课）
2. **模型怎样学会预测？**（5 课）
3. **Transformer 怎样计算上下文表示？**（11 课）
4. **Agent Loop 与工具扩展**（4 课）：软件部件循环、Context 累积、工具调用、MCP。

首页按需载入单个播放器；支持独立 HTML 的暂停、拖动、重播与倍速。学习标记由读者主动勾选并保存在当前浏览器，不会把播放自动计为学会。

## 离线使用

下载仓库 ZIP 并完整解压，打开 `index.html`。不要只移动首页，需保留图片、GIF 和 HTML 的相对目录结构。无需后端、API Key、CDN 或模型服务。

## 教学边界

动画用于概念理解，不是真实 LLM 推理或训练。工具调用课的本地隔离样例函数在构建时真实执行后录制回放；MCP 的连接、发现、调用及结果均为预设教学示意，不连接真实 MCP 服务。

## 发布

本仓库仅包含已发布的静态课件和必要资源，不包含生成过程的逐帧图片、缓存、旧版备份或凭据。GitHub Pages 从 `main` 分支根目录发布；`.nojekyll` 保留静态文件原样发布。
